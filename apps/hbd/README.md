# ✨ おいわいメーカー

名前とメッセージを入れるだけで、**“無駄に凝った”うごくお祝いGIF**が作れるツール。
誕生日・お祝い・記念日・ありがとうに対応。LINE でそのまま送れる。

- 完全ブラウザ内完結（**サーバー不要・月額0円**）
- GIF生成もチャット編集も**すべてクライアントサイド**
- チャット編集は**AI APIを使わない**ルールベース（コストゼロ）
- 課金は Gumroad のライセンスキー方式（透かし消し・高画質を 100円買い切りで解除）

---

## 特長（“LINEでよくない?”を超える）

- **4つのお祝いテーマ**（🎂誕生日 / 🎉お祝い / 💐記念日 / 🌸ありがとう）
- 箔押し風タイポ＋発光＋キラキラ＋シャインスイープの多層合成でリッチな見た目
- モチーフ切替（紙吹雪 / 風船 / ハート / 花びら）
- 決定論的な粒子配置で **GIFがカクつかずキレイにループ**
- テーマを選ぶとメッセージ例も自動で切り替わる（編集すれば固定）

無料＝透かしあり336px / 100円解除＝透かしなし512px。

---

## つかい方（利用者）

1. お祝いの種類を選ぶ → 相手の名前とメッセージを入れる
2. 「ハートを降らせて」「背景を夜空に」などチャットで見た目を調整
3. 「GIFを作る」→ 保存 / 共有（スマホなら LINE に直接送れる）

## お金を受け取れるようにする（Gumroad）

投げ銭ではなく「透かしを消す権利」を売る方式。スマホだけで設定できます。

1. [gumroad.com](https://gumroad.com) でアカウント作成（受取のため本人確認あり）
2. **New product → Digital product** を作成
   - 価格: **100円**
   - **Settings → "Generate a unique license key per sale" を ON**
   - 商品名例: `おいわいメーカー 透かし解除キー`
3. 商品URL末尾の permalink を確認（例 `gumroad.com/l/oiwai` → `oiwai`）
4. `index.html` 冒頭の設定を書き換える：
   ```js
   window.GUMROAD = {
     permalink: 'oiwai',
     productUrl: 'https://gumroad.com/l/oiwai'
   };
   ```
5. commit & push → 完了。購入者はキーを貼って「解除」を押すと透かしが消える。

> ライセンス確認は Gumroad の verify API をブラウザから直接叩くので、
> こちら側のサーバーは一切不要です。
