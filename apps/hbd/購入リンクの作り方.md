# 💳 100円の購入リンクの作り方（あとで見る用）

「気がつけば売上」にするための、集金オンの手順。**スマホだけで完結**します。
※これをやるまでは、💎ネタの購入ボタンは「準備中」表示のままです（＝まだ課金は発生しません）。

---

## ぜんたいの流れ
1. Gumroad で「100円・ライセンスキー付き」の商品を作る（あなたの作業）
2. 商品の `permalink` を1行コードに貼る（私に投げてくれてもOK）
3. push → 反映。以降は購入者がキーを貼ると💎が全解放される

---

## ステップ① Gumroad で商品を作る

1. [gumroad.com](https://gumroad.com) に登録
   - 受け取りのため **本人確認＋振込先（PayPal or 銀行）** の設定が要る（ここだけは本人）
2. **New product → Digital product** を作成
   - **Name（商品名）例:** `おいわいメーカー 全ネタ解放キー`
   - **Price:** `¥100`
   - 中身のファイルは無しでOK（キーだけ売る）
3. 商品の設定で **「Generate a unique license key per sale」を ON**
   - ← これが一番重要。買った人ごとに固有キーが発行される
4. 公開（Publish）

---

## ステップ② permalink を確認

商品URLの末尾が `permalink`。
- 例: `https://gumroad.com/l/oiwai` → permalink は **`oiwai`**

---

## ステップ③ コードに1行入れる

`apps/hbd/index.html` の先頭あたり、ここを書き換える：

```js
window.GUMROAD = {
  permalink: 'oiwai',                          // ← ②で確認したやつ
  productUrl: 'https://gumroad.com/l/oiwai'     // ← 商品ページURL
};
```

→ commit & push すれば完了。（この作業は私に「permalinkは○○」と伝えてくれれば代わりにやります）

---

## 動作（購入者側）
1. 💎ネタで「保存」を押す or 「¥100で作り放題」ボタン → Gumroadの購入ページへ
2. 100円決済 → **ライセンスキー**が届く
3. アプリに戻ってキーを貼って「解除」→ 全ネタ解放（次回以降は自動で解放）

> 仕組み: Gumroadの verify API をブラウザから直接叩くだけ。**こちら側のサーバーは不要**。

---

## 注意・豆知識
- 静的サイトなので技術的には解放をすり抜ける事は可能だが、**100円規模なら割り切ってOK**（大多数は普通に払う）。
- 売上・入金は Gumroad のダッシュボードで確認。
- 値段は後から変えられる（¥100→¥300 等）。まずは¥100で回すのがおすすめ。
