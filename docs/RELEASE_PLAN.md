## 2. 公開プラットフォーム

### 推奨構成：3層展開

```
【メイン】 独自ドメイン（Web アプリ）
    asobiba.app など
    ├─ フロントエンド: Cloudflare Pages（無料）
    ├─ バックエンド:   Railway / Render（月 $5〜）
    └─ DB:            Supabase（無料枠あり）

【発見経路①】 itch.io にも掲載
    Web ゲームとして無料公開
    → インディーゲーム層への露出

【発見経路②】 FF14 コミュニティ直接流入
    Lodestone / X(Twitter) / Discord サーバー
    → コア層への直接リーチ
```

### 各プラットフォーム比較

| プラットフォーム | 向いている点 | 注意点 |
|---|---|---|
| **独自ドメイン** | ブランド確立・課金自由度が高い | サーバー費用がかかる |
| **itch.io** | ゲーマーへの発見性・Pay What You Want | マルチ用サーバーは別途必要 |
| **Discord Activity** | FF14 コミュニティと相性抜群 | 審査あり・実装コストあり |
| **GitHub Pages** | 無料・簡単 | バックエンド不可（マルチ不可） |

### Discord Activity は長期的に検討価値が高い

FF14 プレイヤーの多くが Discord を使用しており、ボイスチャンネルのまま全員でギミック練習できる体験はマルチプレイ機能と完全に相性が良い。

## 3. マネタイズ設計

### 基本方針：「無料で十分使える、でも続けたくなる」

| 無料ユーザー | 有料サポーター |
|---|---|
| ゲームプレイ | 無料の全機能 |
| ステージエディター | AI ギミック生成（無制限） |
| マルチプレイ | 限定プレイヤーカラー |
| AI 生成 月 5 回まで | クレジット表示（支援者一覧） |
| ステージ共有・閲覧 | 新機能の先行アクセス |

### 収益ルート

#### ルート①：Fanbox / BOOTH（最初にやるべき）

```
月額 300円 / 500円 / 1,000円 のプラン
  └─ 特典: AI生成無制限 + 限定カラー + 優先サポート
```

**メリット**
- 決済インフラを自分で作らなくていい
- 審査が比較的簡単
- FF14 層に馴染みがある（創作者支援文化）
- 今すぐ始められる

#### ルート②：AI 生成クレジット購入（中期）

```
無料枠:   月 5 回
クレジット購入:
  500円  → 50 回分
  1,000円 → 120 回分（お得）

実装: Stripe Checkout
```

#### ルート③：ステージマーケットプレイス（長期・夢）

```
クリエイターがステージを公開・販売
  └─ 無料ステージ: 誰でも公開可
  └─ 有料ステージ: 100〜300円
  └─ プラットフォームが 30% 手数料

FF14 新レイドが来るたびに攻略ステージが売れる可能性
```

## 8. AI ギミック生成機能について

### 技術スタック
- **モデル**: Claude Haiku（高速・安価）または Claude Sonnet（精度重視）
- **バックエンド**: `POST /api/parse-stage`（既存 Express サーバーに追加）
- **API キー**: サーバーサイドで保持（クライアントに露出させない）

### 入力例
```
トータル時間 3分30秒

1分30秒に 敵からDPSにランダム2人に追尾AoEが来ます
2分に フィールドの真ん中から大きな吹き飛ばしが来ます
2分30秒に 全員が散開してください
3分に 頭割りが来ます（DPS全員で受ける）
```

### コスト感
- 1 回の生成: 0.5〜2 円（Haiku 使用時）
- 月 5 回無料枠: コスト 2.5〜10 円/ユーザー
- 有料ユーザーは課金で十分回収可能

## 総評

このゲームは **ニッチだが熱量が高いコミュニティ**（FF14 レイド層）に刺さる可能性が高い。  
大きく稼ぐよりも「副業の実績・ポートフォリオ・小さな収益」を最初の目標に置き、コミュニティの反応を見ながら拡大するのが健全な進め方。

**最初の一手**: 本番環境を立てて身内・知人の FF14 プレイヤーに使ってもらい、感想をもらうことから始める。
